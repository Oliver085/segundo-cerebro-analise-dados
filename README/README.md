# Segundo Cérebro: Análise de Dados

## Sobre o projeto

Este repositório documenta a construção do meu segundo cérebro sobre Análise de Dados, utilizando o NotebookLM para organizar fontes, explorar conceitos e consolidar aprendizados.

## Objetivo de aprendizagem

Aprender a analisar dados utilizando Python, SQL, estatística e visualização de dados, aplicando esses conhecimentos em projetos práticos para transformar dados em informações relevantes que apoiem a tomada de decisões e contribuam para a construção do meu portfólio.

## Critérios de seleção das fontes

As fontes são avaliadas considerando os seguintes critérios:

- **Confiabilidade:** verificar a autoria e a origem das informações, priorizando documentação oficial, publicações técnicas e instituições reconhecidas.
- **Relevância:** selecionar materiais relacionados ao objetivo de aprendizagem.
- **Aplicação prática:** priorizar conteúdos com exemplos, exercícios e possibilidades de aplicação em projetos.
- **Atualidade:** verificar se as informações continuam válidas, especialmente em conteúdos relacionados a ferramentas e tecnologias.
- **Complementaridade:** buscar materiais que abordem diferentes aspectos do tema, evitando repetições desnecessárias.
